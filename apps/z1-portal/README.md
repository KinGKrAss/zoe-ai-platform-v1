# Z1 Unified Platform

Single control surface for the Z1 ecosystem.

## Modules
- Z1 Core
- Preussen Point (PPT)
- Finanzfuchs / FORTUNA
- MetaMask wallet integration
- PPT Payments / Merchant layer
- Serum Regalis partner registry
- Z1 Registry / Evidence / Audit

This portal is an orchestration/UI layer. It never receives or stores seed phrases or private keys.

## Payment flow
MetaMask → PPT Portal → PPT Payment → Z1 Audit → Merchant.

## Market flow
Controlled distribution → liquidity → trading, only after contract, reserve, legal and security gates pass.
